# Disable Firmware OTA

<ProCallout />

<br/>

<img src="/ota-modes.png" alt="Modes" width="400px" />

ElegantOTA allows you to selectively enable or disable the update targets of your choice for security reasons, or when you have an important task running that you do not want interrupted by an OTA update. The portal automatically hides a target that has been disabled.

This is about *what* an update is allowed to overwrite - the firmware or the filesystem image - and applies to every [OTA mode](/ota-modes/file).

<Callout type="warning" emoji="⚠️">
This function should be used very carefully as it blocks firmware update! If by mistake this is left disabled, your device will not be recoverable by an OTA update.
</Callout>


#### Enable Firmware OTA
```cpp
// Pass 'true' to enable Firmware mode
ElegantOTA.setFirmwareMode(true);
```
<Callout>
  Both targets are enabled by default on startup (cold boot).
</Callout>

#### Disable Firmware OTA
```cpp
// Pass 'false' to disable Firmware mode
ElegantOTA.setFirmwareMode(false);
```

#### Get firmware target status
```cpp
// You can use this logic inside a function if neccessary
if(ElegantOTA.checkFirmwareMode() == true) {
    Serial.println("Firmware mode is enabled");
} else {
    Serial.println("Firmware mode is disabled");
}
```
